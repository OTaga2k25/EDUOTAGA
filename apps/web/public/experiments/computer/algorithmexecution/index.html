Theory
  • Program Counter (PC): Holds the memory address of the next instruction.
  • Memory: Where program instructions and data are stored.
  • Instruction Register (IR): Holds the current instruction being executed.
  • Registers (A, B): Fast internal memory used by the CPU for calculations.
Observation

During execution, the Program Counter dictates which instruction is fetched. The Instruction Register holds the active instruction. Data moves from Memory to Registers, is processed, and then stored back or outputted. The cycle repeats until the END instruction.
