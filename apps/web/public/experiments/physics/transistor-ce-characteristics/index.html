n-p-n transistor: common-emitter input and output characteristics

Plot the base current IB against VBE (input characteristic), and the collector current IC against VCE for fixed base currents (output characteristic). From them find the input resistance, the output resistance and the current gain β = ΔIC/ΔIB.

The base rheostat sets the base current. The collector rheostat sets VCE. Common emitter: the emitter is shared by the input and output circuits.

—

The idea

In the common-emitter (CE) arrangement the input is applied between base and emitter, and the output is taken between collector and emitter. The base–emitter junction is forward biased and the collector–base junction is reverse biased, so a small base current controls a much larger collector current.

  • Input characteristic (IB against VBE at constant VCE): like a forward-biased diode. Input resistance ri = ΔVBE/ΔIB (about 1 kΩ)
  • Output characteristic (IC against VCE at constant IB): IC rises quickly (saturation region), then becomes almost flat (active region). Output resistance ro = ΔVCE/ΔIC (tens of kΩ)
  • Current gain: β = ΔIC/ΔIB at constant VCE, from two output curves

    Precautions

    • Identify the emitter, base and collector leads correctly before connecting.
    • Keep the base–emitter junction forward biased and the collector–base junction reverse biased (for n-p-n: base and collector positive with respect to the emitter).
    • For the input characteristic keep VCE constant; for the output characteristic keep IB constant, readjusting the base rheostat if it drifts.
    • Take closer readings where the curves bend: near the knee of the input curve and at small VCE on the output curves.
    • Do not exceed the maximum collector current or power rating of the transistor.
